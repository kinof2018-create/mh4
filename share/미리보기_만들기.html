🖼️ 카톡 미리보기 만들기

아래 내용을 입력하면 미리보기가 실시간으로 만들어집니다. 저장을 누르면 저장소의 share/미리보기문구.txt 를 덮어쓰고, Push하면 GitHub가 이미지·제목·설명을 자동으로 새로 만듭니다.

저장 후 GitHub Desktop에서 Push 하면 자동으로 반영됩니다
1
위 칸의 카테고리·제목·내용을 편집합니다.
2
미리보기 내용 저장 버튼 → 저장 창이 뜨면 저장소 share 폴더의 미리보기문구.txt 를 선택해 덮어쓰기 합니다.
3
GitHub Desktop에서 Push → 1~2분 뒤 GitHub가 이미지·제목·설명을 자동으로 새로 만듭니다.
4
카톡은 미리보기를 저장(캐시)하니, developers.kakao.com/tool/clear/og 에서 링크를 넣고 초기화 후 붙여넣으세요.
※ 대시보드(사내 안내판)에는 변화가 없고, 카톡에 링크를 올렸을 때 보이는 미리보기 카드만 바뀝니다.
